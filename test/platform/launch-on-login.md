Purpose: App can launch on login

Scenario: User opts into launching on login
1. Run app
2. Secondary click on tray icon
3. Select "Settings"
4. Enable "Run on login"
5. Logout
6. Login
7. App should be running requesting next task

Scenario: Disable launch on login
1. Run app
2. Secondary click on tray icon
3. Select "Settings"
4. Disable "Run on login"
5. Logout
6. Login
7. App should not be running
