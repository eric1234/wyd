Purpose: App manages timer on suspend/resume

Scenario: User suspends/resumes laptop
1. Run app
2. Input/select task
3. Wait 2 minutes to accumulate time
4. Suspend machine
5. Wait 3 minutes
6. Resume machine
7. Confirm app is asking for next task
8. Secondary click on tray icon
9. Select "Report"
10. Confirm only 2 minutes of time on initial task
